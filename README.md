# Player updates

What Player's Update button installs: `latest.json` names the newest version and its signed update package.
Made by `npm run update-package` and `npm run publish-package` on main; don't edit by hand.

To install by hand, download [Player-1.4.6-update.zip](Player-1.4.6-update.zip?raw=1) and use Settings ▸ About ▸ Update… ▸ Install from Zip… in Player.
